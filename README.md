webappv3

API desarrollada en Flask bajo principios de Clean Architecture.

## Arquitectura

app/
Bootstrap de Flask.

core/
Configuración, utilidades e infraestructura compartida.

services/
Casos de uso del negocio organizados por dominio.

shared/
Componentes reutilizables.

## Instalación

pip install -r requirements.txt

## Ejecución

python run.py
